控制台未连接

App 需要 Termux 里的控制台服务（127.0.0.1:8770）在运行。

  1. 已安装 Termux 并把项目放到 ~/qqbot
  2. Termux 设置里开启外部应用执行：
    编辑 ~/.termux/termux.properties，加入
    allow-external-apps=true
    然后执行 termux-reload-settings
  3. 给本应用授予「Termux: RUN_COMMAND」权限（系统设置 → 应用 → MC收益 → 权限）
也可以打开 Termux 手动执行：
cd ~/qqbot && ./deploy/android/watchdog.sh start
